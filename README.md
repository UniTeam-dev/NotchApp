# NotchApp

Панель в «челке» MacBook. Наведите курсор на вырез камеры — раскроется небольшая панель с музыкой, полкой для файлов, состоянием ИИ-агентов, аккаунтами GitHub и кнопками для частых команд. Уберите курсор — панель спрячется и не занимает места на экране.

Приложение живёт в меню-баре, иконки в Dock у него нет. Нужен Mac с macOS 15 или новее.

## Что умеет

### Музыка
Показывает, что сейчас играет (обложка, название, исполнитель, позиция трека), и даёт кнопки «назад», «пауза» и «вперёд». Работает с Apple Music, Spotify и другими плеерами, которые видит система. Переключаться в плеер не нужно.

### Полка
Временное место для файлов. Поднесите файл к челке — панель раскроется сама, отпустите — файл ляжет на полку. Позже его можно перетащить оттуда в письмо, мессенджер или папку. Удобно, когда нужно перенести файл между окнами и рабочими столами. Файл на полке — это копия, оригинал остаётся на месте.

### Агенты
Показывает, чем заняты ИИ-помощники Claude Code и Cursor, без переключения между окнами:

| Цвет | Состояние | Что это значит |
|---|---|---|
| Синий | работает | агент выполняет задачу |
| Оранжевый | ждёт разрешения | агенту нужно ваше «да» на действие |
| Жёлтый | ждёт ответа | агент задал вопрос |
| Зелёный | готово | задача выполнена |
| Красный | ошибка | что-то пошло не так |

Вокруг челки светится подсветка того же цвета, а когда агент ждёт вас — она «дышит», так что это видно краем глаза. В закрытой челке виден значок состояния и счётчик ожидающих. Сессии, которые ждут вас, всегда наверху списка. Клик по строке открывает нужный чат. Завершённые сессии остаются в списке, пока вы в них не зайдёте, и переживают перезапуск приложения.

### Git
Список ваших аккаунтов GitHub с переключением одним тумблером — для тех, у кого рабочий и личный аккаунты на одном Mac. При переключении меняется и подпись коммитов (имя и почта), чтобы коммиты не ушли от чужого имени. Новый аккаунт добавляется прямо из панели: через код подтверждения в браузере или по токену. Токены хранятся в системной связке ключей, приложение их не сохраняет.

### Терминал
Кнопки для команд, которые вы запускаете часто: «поднять VPN», «показать IP», «запустить сервер». Привяжите команду один раз — дальше она выполняется одним нажатием, а под кнопкой видны статус и последние строки вывода. Долгие команды можно пометить как фоновые и запускать вместе с приложением.

### Настройки
Открываются кнопкой с шестерёнкой в панели или пунктом «Настройки…» в меню иконки в меню-баре.

- **Разделы.** Ненужные вкладки можно выключить — они пропадут из панели и из меню. Если выключить «Агентов», исчезнут подсветка челки и счётчики; если выключить «Полку», панель перестанет раскрываться при перетаскивании файлов.
- **Обновление.** Приложение сверяет свою версию с последним [релизом на GitHub](https://github.com/UniTeam-dev/NotchApp/releases/latest). Если вышла новая — кнопка «Обновить» скачает её, проверит подпись разработчика, заменит приложение и перезапустит его.

### Мелочи
- **Не уходить в сон** — пока включено, экран не гаснет и Mac не засыпает. Полезно на презентациях и при долгих загрузках.
- **Запускать при входе** — включается в меню иконки в меню-баре.
- Любую вкладку можно открыть и из меню-бара, если на вашем экране нет челки.

## Установка

### 1. Приложение

1. Скачайте `NotchApp.dmg` со страницы [релизов](https://github.com/UniTeam-dev/NotchApp/releases/latest).
2. Откройте образ и перетащите **NotchApp** в папку **Applications**.
3. Запустите NotchApp из Applications. В меню-баре появится иконка.

**Первый запуск.** Приложение подписано сертификатом разработчика и проверено (нотаризовано) Apple. macOS спросит подтверждение, что вы хотите открыть приложение, загруженное из интернета, — нажмите «Открыть».

### 2. Зависимости

Само приложение запускается без них, но отдельные вкладки требуют небольших утилит. Они ставятся через [Homebrew](https://brew.sh) — если его нет, сначала установите его по инструкции на сайте.

| Что | Для чего | Как поставить |
|---|---|---|
| `media-control` | вкладка «Музыка»: название трека и обложка | `brew install media-control` |
| GitHub CLI (`gh`) | вкладка «Git» | `brew install gh` |
| Claude Code и/или Cursor | вкладка «Агенты» | с сайтов [claude.com/claude-code](https://claude.com/claude-code) и [cursor.com](https://cursor.com) |

Полка, «Терминал» и «Не уходить в сон» работают без дополнительных утилит.

### 3. Настройка после установки

- **Агенты.** Откройте вкладку «Агенты» и нажмите «Поставить хуки» — после этого Claude Code и Cursor начнут сообщать о своём состоянии. Ваши настройки не перезаписываются: приложение дописывает свои строки и оставляет рядом резервную копию. Cursor после этого нужно перезапустить.
- **Разрешения.** macOS спросит их сама, когда они понадобятся:
  - «Универсальный доступ» — чтобы клик по сессии открывал нужный чат, а не просто окно приложения;
  - «Автоматизация» — при первом обращении к Apple Music или Spotify.
- **Git.** На вкладке «Git» нажмите «Добавить аккаунт» и подтвердите вход на GitHub.

## Удаление

Выйдите из приложения через иконку в меню-баре и удалите `NotchApp.app` из Applications. При желании уберите данные приложения (`~/Library/Application Support/NotchApp`), скрипт хука (`~/.notchapp`) и строки с `notch-hook.sh` из настроек Claude Code и Cursor.

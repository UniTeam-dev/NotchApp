NotchApp — панель у «челки» MacBook: музыка, полка для файлов и состояние
агентов Claude Code и Cursor. Требуется macOS 15 или новее.

УСТАНОВКА

1. Перетащите NotchApp.app в папку Applications (ярлык рядом).

2. Запустите NotchApp из Applications. Приложение подписано и проверено
   (нотаризовано) Apple: при первом запуске macOS спросит подтверждение,
   нажмите «Открыть».

3. Иконка появится в меню-баре. Панель раскрывается наведением на челку;
   файл можно перетащить на неё, чтобы положить на полку.

РАЗРЕШЕНИЯ

• Универсальный доступ (Accessibility) — нужен, чтобы клик по строке сессии
  открывал нужный чат, а не просто поднимал приложение. Система спросит сама,
  выдать можно в «Конфиденциальность и безопасность» → «Универсальный доступ».
• Автоматизация — спросит при первом обращении к Apple Music или Spotify.
• Наведение, перетаскивание файлов и определение играющего приложения
  никаких разрешений не требуют.

АГЕНТЫ

Кнопка «Поставить хуки» на вкладке «Агенты» дописывает хуки NotchApp в
~/.claude/settings.json и ~/.cursor/hooks.json. Ваши настройки не
перезаписываются: файлы сливаются, рядом кладётся копия .notchapp-backup.
Скрипт хука всегда завершается кодом 0 и не может помешать работе агента.
После установки хуков Cursor нужно перезапустить.

Данные приложения: ~/Library/Application Support/NotchApp
Скрипт хука:       ~/.notchapp/notch-hook.sh

УДАЛЕНИЕ

Выйти из приложения через меню-бар, удалить NotchApp.app, при желании убрать
две папки выше и строки с notch-hook.sh из конфигов Claude Code и Cursor.
